    ## Masters' thesis

    1. A guide for the Adams spectral sequence: a computational approach and applications

    This document provides a comprehensive treatment of the Adams spectral sequence. It includes an application associated with the homotopy type of spaces of long knots. The computational tool used to perform computations was the author's software \( [ \texttt{minr.py} ] \). Some byproducts of this work include \( \left[ P_\bullet \stackrel{\cong}\longrightarrow \mathbb{F}_2 \right] \) (mobile ver.), \( \left[ \mathrm{Ext}^{s,t-s}_{\mathcal{A}_2}(\mathbb{F}_2, \mathbb{F}_2 ) \right] \), \( [ \mathrm{mod} \; 3 ]\), \( [ \mathrm{mod} \; 5 ]\), \( [ \mathrm{mod} \; 7 ]\), \( \left[ \mathrm{Ext}^{s,t-s}_{\mathcal{A}_3}\left( \mathbb{S}_{hD_3}^{\rho_3}, \mathbb{F}_3 \right) \right] \).

    # Programming

    I have been coding for most of my life. I encourage you to visit my GitHub repository @issyl-m, where you can find some of my older x86 assembly code and projects. Some of these programs (2012) are difficult to replicate, even with modern LLMs (2026), without human expertise. Of course, it is straightforward to recover some relevant memory offsets from my GitHub repository.

    Coding also serves as a recreational activity and an effective tool for mathematical outreach. Along those lines, I uploaded some interactive Manim animations (inspired by @3blue1brown) to my YouTube channel @Andres-Moran-L, coded in Python for the PUC (Chile) math club.

    I have a background in React, PHP, Node.js, JavaScript, HTML, and SCSS, and a strong background in desktop application development (Windows), ranging from Python to C, C++, C#, VB.NET, and ASM. I have reverse engineering experience on x86 architectures, mostly at Ring 3 level, but I am familiar with Windows internals. I even debugged code on MIPS 1 architecture (MIPS R3000). My favorite debuggers are WinDbg, GDB (+pwndbg), and x64dbg. I also like Angr, Ghidra, and IDA Pro. Regarding agentic coding solutions, AGY and OpenCode are suitable options.
